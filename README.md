# CentroXpert - Ingeniería y Servicios
### Aplicación Web para Gestión de Proyectos, Levantamientos Técnicos, Logística y Flotilla

Plataforma operativa diseñada para la coordinación de cuadrillas en campo, control de presupuestos y gestión logística integral.

---

## 🚀 Pasos para Desplegar en GitHub Pages

1. **Crear Repositorio en GitHub:**
   - Entra a [github.com/new](https://github.com/new).
   - Asigna un nombre a tu repositorio (ejemplo: `centroxpert-app`).
   - Selecciónalo como **Public**.
   - Haz clic en **Create repository**.

2. **Subir los Archivos:**
   - Haz clic en **Upload an existing file**.
   - Sube el archivo `index.html` y este `README.md`.
   - Haz clic en **Commit changes**.

3. **Activar GitHub Pages:**
   - Ve a la pestaña **Settings** del repositorio.
   - En el menú lateral izquierdo, selecciona **Pages**.
   - Bajo **Build and deployment > Branch**, selecciona `main` (o `master`) y la carpeta `/ (root)`.
   - Presiona **Save**.
   - En unos segundos, GitHub te proporcionará el enlace público (ejemplo: `https://tu-usuario.github.io/centroxpert-app/`) para compartir con los técnicos.

## 📋 Módulos Incluidos

- **Importación de Órdenes PDF:** Procesamiento de órdenes de servicio de CentroXpert.
- **Geolocalización GPS & Mapas:** Botón para navegar al destino con Google Maps y registro horario de llegada/salida con coordenadas.
- **Levantamiento Digital & OCR:** Registro de metrado, tipo de cielo/ducto, notas de campo y búsqueda directa en el catálogo de `tienda.omega.com.do`.
- **Módulo de Logística y Flotilla:**
  - Contador de vehículos disponibles en tiempo real.
  - Control de combustible y rendimiento en km/galón con comparativa frente a distancias estimadas por GPS.
  - Clasificación de técnicos por niveles: Especialista A, Especialista B y Auxiliar Técnico.
  - Inventario y asignación de herramientas y equipos de medición.
